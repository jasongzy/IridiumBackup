<h1 align="center">铱备份</h1>

[English](README.md) | 简体中文

铱备份是一款现代化的原生 Android 备份工具，延续了[钛备份](https://www.titaniumtrack.com/titanium-backup.html)的核心功能与以应用为中心的操作方式。需要 Root 权限。

## ✨ 功能

- 为每个应用保留和管理多个备份记录
- 自由选择 APK 与数据范围，支持单个及批量备份、恢复
- 使用彩色标签、备注、筛选、搜索和排序管理应用与备份
- 直接导入钛备份的备份记录、备注和用户标签
- 按保留数量批量清理旧备份，保留受保护的备份
- 校验本地备份完整性，并支持从备份目录重建索引
- 支持本地存储及云存储服务
- 支持 Android 多用户与系统应用

## 📥 下载

请从 [GitHub 最新版本](https://github.com/jasongzy/IridiumBackup/releases/latest) 下载通用 APK。

- Android 7.0 或更高版本
- 通过兼容的 Root 方案获得超级用户权限
